# Definition of Done

Una issue está Done sólo si satisface lo que aplica:

## Ingeniería
- criterios de aceptación cumplidos;
- tests pasan;
- typing/lint acordados;
- migrations reversibles/revisadas;
- errores manejados;
- docs/API actualizadas;
- PR revisada por humano.

## Ciencia
- definición matemática documentada;
- referencia/justificación;
- casos manuales conocidos en tests;
- unidades/rango/convención explícitos;
- no rompe comparabilidad experimental;
- reproducibilidad registrada.

## Replay/datos
- leakage tests;
- dataset/scenario version;
- timestamps y timezone correctos;
- outcome no filtrado.

## UI
- accesibilidad básica;
- estados loading/error/empty;
- E2E relevante;
- no dark patterns de trading.
