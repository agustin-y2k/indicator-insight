# Research Data Protocol

## Separación de datos
- datos de identidad/contacto: mínimos y separados;
- datos experimentales: participant pseudonym;
- datos financieros históricos: dataset snapshots independientes.

## Ciclo
1. obtención/licencia documentada;
2. validación de schema;
3. snapshot inmutable;
4. hash;
5. generación de escenarios;
6. freeze de pool;
7. experimento;
8. exportación desidentificada;
9. análisis;
10. retención/eliminación según normativa institucional.

## Calidad
Documentar missing data, splits, ajustes, calendarios, activos, horizonte y limitaciones del universo. No imputar silenciosamente.
