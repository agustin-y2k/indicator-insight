# ADR 0005 — Use Kanban and milestones without a fixed 16-week plan

**Status:** Accepted

## Context
There is no academic 16-week constraint and artificial sprints would make the research plan misleading.

## Decision
Linear manages continuous flow with WIP limits and milestones; dates are added only when real institutional deadlines exist.

## Consequences
This decision is part of Thesis Baseline. Supersede it with a new ADR rather than silently editing the rationale after implementation/experimentation begins.
